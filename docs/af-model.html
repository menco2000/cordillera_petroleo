Cordillera Petróleo AF Model

Fictional oil & gas company with 8 metropolitan sites across South America. Each site has its own oil field and its own refinery. The hierarchy follows ISA-95 equipment levels, and the ISA-88 physical model names the refinery units. Every element and attribute below comes from model/spec.py, the same file that generates the AF XML and drives the simulator.

1 · Structure

How a site is organized

Every site has the same structure. The only differences are the number of wells, their lift methods and the equipment sizing. The diagram follows the product from the wells to the product tanks. Swimlanes are ISA-95 areas, inner boxes are work centers (ISA-88 process cells), and nodes are work units and equipment modules.

Conventions

Names
Elements carry human names (Garzas-01, Crude Charge Pump). The asset ID (BAR-W01, BAR-P-101) lives in the Asset ID attribute.
Tag name
Built from the ID: CP.<SITE>.<ASSET>.<SUFFIX>, e.g. CP.BAR.P101.FLOW. Stored in Tag Prefix; templates use %@Tag Prefix%.
Depth
5 levels maximum: Enterprise › Site › Area › Work Center › Work Unit.
Server
All PI Point references read the server from the PI Server attribute on Cordillera Petróleo (PISERVER).
Points
Every PI Point reference carries its creation settings: point source L (Lab), compression off, point type and engineering units. Status tags are Int32 read through AF enumeration sets.
Units
Oilfield units: psig/psia, bbl/d, Mscf/d, °F. Units missing from the default AF UOM database (Mscf/d, lb/h, spm…) live in the PI point and attribute description.
Rollups
Field totals, tank farm inventory and company totals are Rollup analyses.
ISA-88 use
ISA-88 is a batch standard and a refinery runs continuously. So we use its physical model names, and the Extraction Run event frame is the record of each production run.

6 · Simulator

Scenarios the simulator will produce

The simulator runs on your network. It backfills about 90 days of history, then keeps writing in real time through PI Web API. Variables are physically coupled, so cause and effect show up in the data. That is what you need for forecasting and pattern recognition.
